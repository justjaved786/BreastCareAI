Understanding Your Results

The system analyzed the provided numerical feature values using trained machine learning models. These models learn statistical patterns from labeled dataset samples and apply them to new inputs.

The analysis focuses on the following dataset-derived features:

  • Radius (Mean): Average distance from the center to boundary points
  • Texture (Mean): Variation in gray-scale intensity values
  • Perimeter (Mean): Average length of the cell boundary
  • Area (Mean): Average size of the cell region
  • Smoothness (Mean): Local variation in boundary smoothness
  • Compactness (Mean): Perimeter² divided by area (normalized)
  • Concavity (Mean): Degree of inward curvature in the boundary
  • Concave Points (Mean): Number of concave boundary points

The selected machine learning model outputs a probability score indicating how closely the input data matches learned patterns. This score represents model confidence and is not a medical diagnosis.
